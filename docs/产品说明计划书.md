# 《全巢之力》产品说明计划书

> **赛道**：跨次元游乐场（AI 游戏与互动叙事）
> **可运行 Demo**：https://quanchaozhili.vercel.app
> **开源仓库**：https://github.com/wangchi2068/quanchaozhili
> **一句话**：把一个知乎高赞回答，做成一场「你不知道自己被信过」的互动叙事。

---

## 一、核心思路

### 1.1 起点：一篇 6.5 万赞的知乎回答

本作改编自知乎答主 **@狐狸** 的回答《克苏鲁可以被卑微的人类召唤，那人类可以被蚂蚁召唤吗？》（65541 赞）。那个回答之所以动人，是因为它把「向古神许愿」这件宏大的事，压到了一段水泥台阶上：一窝蚂蚁用亮晶晶的粉末围成一个圆，用身体拼出你的名字——**缺了最后一笔**——然后拼尽全力开口：

> 「全宇宙最尊贵、最仁慈的存在，请不要走。」

于是有了这个游戏：**你叫张亮，你只是一个刚下班、拎着外卖回家的普通人。而你不知道自己被信过。**

### 1.2 命题：神性由轻慢构成，信仰由误读构成

这不是一个"扮演神"的游戏，而是一个"被人当成神而你毫无察觉"的游戏。玩家从头到尾没有做错任何事，蚂蚁也没有做错任何事——悲剧只是发生了，发生在两者的**尺度落差**与**认知落差**之间。

**尺度落差**：1 人类身高 ≈ 570 只蚂蚁。你踩过的台阶对它们是一片需要跋涉的高原；你的一步是七级地震，一次呼吸是飓风，随手一块饼干屑是全巢三个月口粮，两袋超市打折的白砂糖是几代人都耗不完的能源，一壶开水是灭世的大洪水。

**认知落差**：这才是本作真正的引擎——见 1.4。

### 1.3 玩法主张：神没有技能栏

玩家唯一的"能力"是**随手**。没有属性面板、没有神力值、没有技能树。你能做的只有像平常一样生活：蹲下来看、站起来走开、掏手机拍照、补上缺的那一笔、回应那句"请不要走"。

**这个设计选择的重量在于**：玩家不是故意作恶，他只是没有意识到自己在做什么。这比"扮演一个坏人"难写得多，也痛得多。

而且**世界不为玩家暂停**：你可以拒绝显灵，法阵就会越来越亮、越来越频繁；你可以无视献祭，那一派会改而自我绝食；你可以不理会兵蚁统帅的请令——它会替你打了那场仗，并宣称是奉神谕。拒绝的代价是真实的，主线锚点不会被跳过。

### 1.4 签名机制「经文」：一个会撒谎的叙述者

**一句话：蚂蚁如何记载神做过的事，与神实际做了什么，永远是两回事。**

你在台阶上顺手踩死一只兵蚁。世界上真实发生的事是：你鞋底落下，0.3 秒，你甚至没低头。

而蚁巢的经文里发生的事是：**「神降下雷霆，诛灭僭越者。」**

这不是文案上的花活，而是一个**结构化的机制**：每个回合，旁侧记账模型把玩家做过的事翻译成蚁群的神学语言，写进账本，并且**允许记歪**——条目按三段式落盘，玩家随时可以打开手账读到：

```json
{ "key": "经文·天罚篇",
  "desc": "神实际做了：随手踩死了一只兵蚁 ／ 蚁群记为：神降下天罚，诛灭邻巢僭越者 ／ 记歪在：把一次无意的踩踏记成了宗教裁决" }
```

**为什么写死就废**：歪解的方向取决于当前话语权最大的派系（维尔派记为恩典、女王派记为资源、灰烬派记为号召、逆记为祸根），而"谁话语权最大"由玩家的历史选择动态决定；再加上蚁的世代以周计，旧经文还会被一代代改写——你翻回前三幕的条目，会发现它已经不是同一件事了。任何预写脚本都会在第三次被玩家识破。

### 1.5 六幕：从荒诞喜剧滑向不可回避的一夜

| 幕 | 情境 | 你要面对的事 |
| --- | --- | --- |
| 一 · 显灵 | 台阶上的圆阵、缺笔的名字「张亮」 | 是否驻足、是否补全末笔 |
| 二 · 应许 | 两个小小的愿望：诛杀邻巢战士、赐一座山一样高的砂糖 | 你照做了（"毕竟……为什么不呢？"） |
| 三 · 狂热 | 糖是能源。繁荣、分裂、献祭、圣战 | 你反驳不了任何一个教派 |
| 四 · 求爱者 | 提米求你让它成为"她眼中唯一的存在" | **你解决不了这个问题** |
| 五 · 覆巢 | 一个最平凡的「顺手」动作，或者你什么也没做 | **这一夜躲不掉** |
| 六 · 新世代 | 幸存者重建召唤仪式，经文第一页刻着戒律 | 你又路过那个台阶 |

**第五幕是刻意的强制锚点，且结果固定、方法不限**：巢内除提米与缇尔外全灭，逆因独居巢外幸存；但那一击不必是原著那壶开水——倒水、拖地、扫地、一脚，乃至「我什么都不做」都成立，祸因只能追到神身上。这一幕以提米那句「**我他妈都许了什么愿啊**」为收束闸门：这句话不出现，主线就不许翻页（超时兜底防卡死）。因为这场灾难必须由玩家亲手造成，这个游戏才成立。

终局由账本里的状态变量（信仰度、怀疑度、巢群规模、四派势力消长）与玩家历次抉择共同判定，**四条可达**：应验者（最接近原著：千年后新世代重演旧事，名字已经念歪，什么都没学会）／大洪水（你第一次读懂了经文，但那已是事后，不给救赎）／离场（你搬走了，它们在无神的世界里自己活了下来）／造物主（灰烬派逻辑闭环，你成了被自己信徒吃空的神）。

## 二、技术方案

### 2.1 架构主张：确定性代码管状态，模型只管生成

本作跑在一套**状态化 LLM Agent 运行时**上：引擎与内容彻底解耦，**换掉 `assets/campaigns/` 下的一个目录，就是另一个故事**。游戏的记忆、状态、主线进度全部由确定性代码掌管；模型只负责一件事——把这一刻写活。

具体分工：

- **状态**（信仰/怀疑/巢群/派系/世代）→ 结构化记忆账本，由旁侧模型从正文里抽取，玩家不能直接改（想降信仰，只能靠剧情行为）；
- **主线**（六幕推进）→ 导演按 `arc.json` 的解锁关键词 + 回合门槛 + 防连跳间隔规则化推进，支持「不可回避的锚点」；
- **文本**（台词/经文/结局）→ 模型生成；
- **玩家可见性** → 右侧「蚁巢手账」五个分页：主线 / 人物 / **经文** / 前情 / 世界线。

### 2.2 一组通用能力，被一套战役内容完整复用

除签名机制外，本作的机制**默认零代码改动**，全部复用运行时已有能力：

| 本作机制 | 运行时模块 |
| --- | --- |
| 叙述者与七只蚂蚁 | 角色卡 v2 + system 组装（维尔/蚁后/提米/缇尔/逆/灰烬/断颚，七张卡） |
| 尺度换算与四派神学 | 世界书混合激活（关键词 + 向量召回） |
| 六幕主线与原著锚点 | 主线导演 + `arc.json`（关键词、门槛、收束闸门、必发生事件） |
| 信仰/巢群/怀疑/派系 | 记忆账本（固定 key 的 notes 条目，`/state` 可见） |
| 神谕卡（重大抉择） | 决策卡（2–4 个候选方向 + 自由输入，留痕 `decisions.jsonl`） |
| 神的物理后果掷真随机 | 掷骰卡（用户亲自投 D20，模型不得擅改点数） |
| 前情提要与世代压缩 | 上下文工程（三层重裁 + 旁侧模型压缩） |
| 存档 / 回档 / 世界线 | 世界线快照（回档前自动留档） |

### 2.3 上下文工程：长对话不越窗、不失忆

每一轮按预算重裁，只保留「人设 + 世界书 + 账本 → 剧情化摘要 → 近期原文」三层；超预算时由旁侧模型把最旧剧情压成**保留专有名词与伏笔**的前情提要。压缩欠账异步补压，不阻塞玩家。

### 2.4 每回合 AI 配图：正文先出、图后补

每个回合正文出完后，服务端异步再做一件事：用旁侧模型把这段剧情提炼成一句画面描述，再交给图像模型画一张，贴在消息下方。**全程不阻塞对话**；图只走 UI，不进对话历史（否则 base64 会把上下文撑爆）；失败一律静默降级。取图接口直接回图片字节（不是 JSON+base64，那会把体积撑大 33%）。同一个会话里同一个回合的图会复用。

美术方向是硬的：**微距夜行 + 神永远不在画面里**——只允许用画框外压下来的暗影与暖光暗示其存在。

### 2.5 工程质量与实测

- **零构建**：Node ≥ 22 原生运行 TypeScript，无打包步骤；运行时只依赖一个第三方包（`ws`），HTTP 服务、OpenAI 兼容客户端、向量召回、PNG 卡解析全部手写
- **75 个单元测试全过**；`tsc --noEmit` 严格模式零错误
- **单回合延迟**约 19–25 秒（含正文 + 记账 + 主线判定）；单回合配图约 6–20 秒，正文先出不阻塞
- **零成本部署**：Vercel serverless，已上线并对外可点
- 面对真实使用做过加固：空正文自愈重试、防卡死超时兜底、移动端抽屉、正文在虚化底纹下最坏对比度 14.1:1（无障碍 AAA 为 7:1）
- **可观测**：`/metrics` 暴露 token 用量、延迟分位、provider 切换、记账成败

## 三、与知乎生态的契合度

赛道说「跨次元游乐场」要做的是：**把知乎的故事、人物、知识和社区文化，转化为可参与、可探索的互动体验。** 这一条不是我们贴上去的标签，而是本作从第一天起的设计前提——逐条对应如下。

### 3.1 「知乎的故事」是现成的素材库，而本作已经跑通了一次转化

知乎回答区里躺着的，是大量**已成型的、有情绪张力、有完整起承转合**的中短篇叙事。它们天生适合被"翻译"成互动体验：有明确的主人公、有抉择点、有一句能被记住的题眼。

本作就是一次完整的示范：一篇回答 → 六幕主线（`arc.json`，含每幕目标、必发生事件、情绪基调与张力值）→ 七张角色卡 → 一份世界书 → 四个结局。**第 1–5 幕忠于原著情节，第 6 幕为 AI 演绎补完**，游戏内显著标注出处并可跳回原回答。

### 3.2 关键在「可复制」：换一个目录就是一个新战役

如果只是把一篇文章做成一个游戏，那是一次手工活。本作的架构主张让它变成一条**管线**：

```
assets/campaigns/ants/      ← 本作的全部内容
  arc.json                  六幕主线（关键词 / 门槛 / 锚点 / 收束闸门）
  card-ants.json            叙述者卡 + 内嵌运行规则
  worldbook.json            世界设定
  npcs/                     七张角色卡
  endings.md                结局清单与判定依据
```

**运行时与内容完全解耦，零代码改动即可换一个故事。** 这让"把一篇知乎回答变成一个游戏"从作品变成了工具：任何一篇有叙事张力的回答，都能按同一套骨架装进来。这是我们希望交给知乎生态的东西——不是一款游戏，而是一条**内容转化的生产线**。

### 3.3 「知乎的社区文化」不是背景，而是本作的核心机制

这一点是契合度里最实的一层：**本作的签名机制「经文」，本质上就是评论区。**

同一个事实落到不同立场的人手里，会得到彼此不相容的解读——这正是知乎讨论区的日常。游戏把它做成了可玩的机制：

| 游戏内 | 现实里 |
| --- | --- |
| 维尔派：神是仁慈的，一切皆有深意 | 虔诚的拥护者，把一切解释成善意 |
| 女王派：神是可预测的天气，别浪费力气诵名 | 实用主义者，只算成本收益 |
| 灰烬派：神喜饱足，未让神饱足是我们的罪 | 极端化的信徒，越回应越确信 |
| 不许愿者（逆）：上一次应允，我们死了多少？ | 冷静的质疑者，最后活下来的往往是它 |
| **经文记歪**：同一件事被一代代改写 | **同一件事在传播中被立场重塑** |

同一句神谕落下，四个派系必须各自解读并各记一条经文——一个"我不管了"，维尔记为「神在试炼我们」，女王记为「上面那位撤资了」，灰烬记为「神厌弃我们，故当自焚以谢」，逆只说两个字：「看吧。」

**玩家随时可以打开账本，读到一条刚出炉的、把自己随手记成神迹的经文。** 这种"被误读"的体验，是知乎用户再熟悉不过的东西。

### 3.4 账号与身份：知乎登录已接入

本作已实现知乎 OAuth 授权入口与回调端点：

- 授权发起：`/api/auth/zhihu/login`
- 回调接收：`/api/auth/zhihu/callback`（已在提交材料中登记）
- 授权成功后，界面顶栏以**知乎昵称**署名（「神 · 你的知乎 ID」），玩家以自己的知乎身份进入这段叙事
- 未配置 APP_ID / KEY 时自动回落到本地身份，不阻塞游玩

这条链路的想象空间是具体的：**「我是这个神的第几代信徒」可以成为一个真实的、可分享的知乎身份。**

### 3.5 「知识」也在场：蚁群生物学与尺度换算

知乎的气质里有一半是"知识"。本作没有把它做成说教，而是做成**可探索的世界书**（游戏内 `/lore 词` 随时可查）：真实的蚁群社会结构（育婴室 / 菌圃 / 粮仓 / 信息素通讯）、工蚁寿命以周计而蚁后最长寿、570 倍尺度换算表、"发声"与诵名礼的生物学基础（极少数蚂蚁通过摩擦腹部与后腿发出气音）。

**玩家不是被科普，而是在被这个设定伤害的时候，顺手学到了它。**

### 3.6 回流：让玩家把经文带回知乎

终局之后，玩家手里的东西是**一份完整的、由他自己的选择生成的经文档案**（本作已支持一键导出 Markdown / Word）。顺着这条线，下一步可以做成：把终局经文一键发成一条知乎想法，让"我用了几代信徒、造了什么孽、经文里被记成什么"成为可被讨论的内容——**游戏的终点，回到社区的起点。**

### 3.7 合规与边界

- **署名**：首屏、开场白与仓库 README 均显著标注原作者 @狐狸 与原文链接，游戏内可跳回原回答
- **边界**：第 1–5 幕忠于原著情节、第 6 幕为 AI 演绎补完；**未逐字复制原文长段**（唯一照写的是那句题眼「向古神许愿时，必须以百分之一万的谨慎态度审视愿望中的每一个字」）；非原作者作品，不构成对原作者的权利主张
- **用途**：知乎黑客松参赛演示，**非商业性的衍生技术探索**，赛后如需使用请联系原作者
- **内容边界**：故事涉及微小生命的死亡，但**不作血腥描写**；配图硬性禁止人体、血液、器官与侵入性操作——重量交给纸、灯与时间，不靠生理刺激

## 五、一句话收束

> 这个游戏里没有神。
> 只有一群微小到看不见的生灵，把一次路过的偶然，解释成了全部意义。
> **而你不知道自己被信过。**
