# 《全巢之力》游戏简介

## 一句话
你是一个加班到深夜的普通人，蹲下来之前，蚂蚁已经把你奉为神——而这场信仰，将以你想象不到的方式回响千年……

---

## 你玩什么
一个夏夜，你拎着外卖在自家门口台阶上，发现一小圈亮晶晶的粉末围成的圆，圆心是你缺了最后一笔的名字「张亮」。一群蚂蚁在用几乎听不见的声音诵念——它们召唤了一个"神"，而那个神，是你。

游戏里没有打怪、没有数值面板、没有神力值，你只需要像平常一样生活：蹲下来看、走开、拍照、补上最后一笔、回应那句"请不要走"。你做的每个随手动作都会被旁侧模型记录并"记歪"写进账本，成为世界状态的一部分，并在几幕之后以你认不出的方式反噬回来。

---

## 世界观：神与尺度

### 尺度换算
1 人类身高 ≈ 570 只蚂蚁。你踩过的台阶，对它们是一片需要跋涉的高原；你的一步是七级地震，拎回的两袋白砂糖是几代耗不完的能源，你的一壶开水是灭世的大洪水。

### 四派神学（蚂蚁内部对"神"的四种解释）
- **维尔派（虔诚记录派）**：神是仁慈与至高的，凡神所行必有深意，愿望会被听见；
- **女王派（实用主义）**：神等于可预测的天气，只在乎粮仓与繁衍，不诵名也不献祭；
- **灰烬派（狂热献祭派）**：神喜饱足，未让神饱足是我们的罪，排队等候神踩踏以归于神腹；
- **不许愿者（逆·怀疑派）**：全巢唯一拒绝许愿并远离神迹的蚂蚁，它的戒律是"向神许愿时，必须以百分之一万的谨慎态度审视愿望中的每一个字"。

## 故事弧线：六幕

```
显灵 → 应许 → 狂热 → 求爱者 → 覆巢 → 新世代
```

从"你成为神"的荒诞喜剧，滑向"许愿被扭曲实现"的宿命悲剧：
- **第一至四幕**：从降临台阶、恩赐两袋白砂糖的狂欢，演进到数代后微小底层工蚁提米向你倾吐求爱愿望；
- **第五幕（覆巢）**：神想到了最省事的解法。巢内几乎全灭，唯独提米、缇尔与独居巢外的逆存活。提米醒来面对满地族人痛哭悔恨；
- **第六幕（新世代）**：多年后你在同一台阶再次路过，新生蚁群带着刻有血泪戒律的经文，再次重构召唤仪式。

---

## 结局：四个可触发分支

终局由记忆账本中的信仰度、怀疑度、派系势力消长与玩家历次神谕抉择综合判定：

| 结局 | 结局类型 | 一句话特征 |
| :--- | :--- | :--- |
| **① 应验者** | 原著结局 · 循环 | 千年后新世代重新学会画圆、诵名，名字传抄走样，而神依然不知自己被信过——什么都没学会。 |
| **② 大洪水** | 悔悟 · 不可逆 | 你终于第一次读懂了经文上记录的罪行，但那已是灾难之后——这个结局不给救赎。 |
| **③ 离场** | 哲学分支 | 你搬家走了，台阶再无圆阵。它们在没有神的世界里发展出了一套独立神学，信仰自己活了下来。 |
| **④ 造物主** | 极端献祭 | 灰烬派逻辑闭环，信徒排队走向你的脚底直到全巢搬空——你成了被自己信徒吃空的神。 |

---

## 核心命题
**神性由轻慢构成，信仰由误读构成。**

这既是一个关于"被崇拜者"的黑色寓言，也是关于"崇拜者"的温情悲剧——你从头到尾只是过着自己的疲惫日常，蚂蚁也只是真挚地生存与祈求，悲剧却在两者的尺度与认知落差中不可逆地发生。

---

## 技术与设计卖点

1. **状态化 LLM Agent 叙事运行时**：引擎与剧本数据彻底解耦，确定性状态机管记忆与剧情约束，大模型专注于高质量角色扮演与叙事生成。
2. **签名机制「经文记歪」**：旁侧模型每回合实时提炼玩家事实行为，按蚁群当下主导教派的偏见翻译成神学记录，玩家可在手账面板实时审阅自己被如何歪曲。
3. **每回合 AI 原生电影感配图**：遵循"实拍微距摄影 + 神永不入画"的苛刻视觉铁律，正文流式呈现后异步配图，既不阻塞对话，又让画面随情节推进流转。
4. **轻量与零构建**：基于原生 Node.js 与单一基础依赖打造，秒级响应，已全量上线 Vercel Serverless 环境。
