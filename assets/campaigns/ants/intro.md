# 序章剧本：台阶（幕一开场）

> 运行时开场白以 `card-ants.json` 的 `first_mes` 为准（AI 逐字播放）。
> 本文件为剧本存档，供调整/复述。第一至五幕忠于 @狐狸 原著，第六幕为演绎。

## 场景

夏夜。楼道声控灯亮一下又灭。你一手拎着外卖，一手在兜里摸钥匙，鞋底黏着已经发黑的口香糖。家门口的台阶上，有一小圈东西在反光。

## 要素（按序出现）

1. **日常铺垫**：外卖、钥匙、口香糖、改了三遍的方案——先把"神"还原成一个疲惫的普通人
2. **反光**：台阶砖缝前一小圈极整齐的亮晶晶粉末，围成一个圆
3. **字**：圆中央一串歪扭的笔画——是你的名字，缺了最后一笔
4. **声**：几乎听不见的、有节奏的"嘶——嘶——"，像耳鸣；几只蚂蚁腹部一收一放，在发声
5. **巢的暗示**：砖缝的黑影深处，密密麻麻还有什么在动
6. **开口**：蚂蚁（司名者维尔领诵）发出请求——"请不要走"

## 选择点（幕一）

- 蹲下来看 / 站起来走开 / 掏出手机拍照 / 假装没看见继续开门
- 对那串缺笔的名字：替它们补上最后一笔 / 抹掉 / 什么也不做
- 是否回应那句"请不要走"（回应＝正式成为它们的神；沉默也是一种回应）

## 幕一推进条件

- 最近剧情中出现"法阵 / 圆阵 / 名字 / 诵念 / 召唤"任意关键词
- 至少 1 回合
- 推进钩子：「全宇宙最尊贵、最仁慈的存在，请不要走。我们尽全巢之力召唤您的降临，只是希望您能聆听我们的愿望。」

## 第一幕的隐藏任务（不给玩家看）

让玩家在完全放松的状态下接受"自己是神"这件事——不接受也没关系，法阵会一直亮着，等到他某天终于蹲下来。
